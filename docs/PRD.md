# 私有护理题库系统 · PRD

- **项目**：private-tiku
- **技术栈建议**：Vite + React + MUI + Tailwind CSS；后端建议 Python/FastAPI + SQLite（FTS5），Docker 部署（待架构师定）
- **原始需求**：把护理试题文档（DOCX/TXT/PDF）变成可快速搜索答案的私有题库；自动识别题号/题干/选项/答案/题型；支持全文搜索；标记缺答案、格式异常题目；支持 Docker 私有化部署。

## 1. 产品目标

把散乱的护理试题文档变成可秒级检索、可校对异常的私有题库，数据不出内网。

## 2. 用户故事

1. 作为护理教研老师，我想批量导入 DOCX/TXT/PDF，以便一次性建库，无需逐题手工录入。
2. 作为备考学生，我想按题干/选项/答案/解析关键词搜索，以便几秒内定位题目与答案。
3. 作为题库管理员，我想看到缺答案、缺选项、题号重复、无题干的异常清单，以便批量校对修正。
4. 作为运维人员，我想用 Docker 一键部署到内网服务器，以便数据不依赖公网。
5. 作为教研老师，我想在入库前预览解析结果，以便拦截脏数据。

### v1.3.4 Markdown 格式规范

**最小可用样例（等价于本系统导出，必须 100% 往返）**

```markdown
# 私有护理题库导出

- 导出时间：2025-01-01 10:00:00
- 题目总数：1

## 1. [单选题]

脉搏短绌最常见于下列哪种心律失常？

- **A.** 心房颤动
- **B.** 心室颤动
- **C.** 心房扑动
- **D.** 期前收缩

**答案**：A

**解析**：脉搏短绌指脉率少于心率，为房颤的典型体征。

**来源**：护基1.docx
```

判断题更短：`## 2. [判断题]` + 题干 + `**答案**：√`，无选项行。

**逐行写法约定**

| 元素 | 规定写法 | 必需 |
|---|---|---|
| 文件头 | 首行 `# 任意标题` 之后、第一个 `## ` 之前的内容整块忽略（导出文件的时间/总数统计无害） | 否 |
| 题目起始 | `## {题号}. [{题型}]`，题型取 `单选题｜多选题｜判断题` | **是** |
| 题干 | 题目起始行之后的第一段非空文本（直到选项行/答案行） | **是** |
| 选项 | 每行 `- **{字母}.** 文本`，字母 A–H | 选择题必需 |
| 答案 | `**答案**：{内容}`，选择题为字母组合（如 `ABC`，大小写均可、内部空格忽略），判断题为 `√` 或 `×` | **是** |
| 解析 | `**解析**：{文本}`，可跨多行，遇到下一个 `## ` 或 `---` 结束 | 否 |
| 来源 | `**来源**：{文本}`，**导入时忽略**（来源统一取上传文件名，避免重导入后来源漂移） | 否 |
| 分隔线 | `---`，有无均可（分题以 `## ` 标题为准） | 否 |

**必须容忍的变体（人手写常见写法）**

- 题号：`## 1. [单选题]`、`## 1、[单选题]`、`## 1 [单选题]`、`## 第1题 [单选题]`（题号非数字时按出现顺序补 1..n）；题型标记可用 `[单选题]`、`（单选题）`、`【单选题】`、英文 `[single]/[multiple]/[judge]`；**缺省题型**时按「有无选项 + 答案字母个数」推断（复用 JSON 导入的 `decide_qtype`）
- 选项：`- **A.** x`、`- A. x`、`- **A、** x`、无列表符的 `A. x`、`A：x`
- 答案：`**答案**：`、`**答案**:`、`答案：`、`正确答案：`、`参考答案：`；判断题答案可用 `√/×`、`对/错`、`正确/错误`、`T/F`（`A/B` 仅在选项内容确为「正确/错误」时映射为 √/×）
- 解析：`**解析**：`、`解析：`、`**分析**：`、`**解答**：`；空题干占位 `（题干为空）` 视为空题干（沿用导出占位，落 `empty_stem`）
- 空白与编码：CRLF/LF、全角空格、BOM、大小写不敏感；编码沿用现有 `_decode_bytes` 兜底

**分片与报错**：单个 `.md` 恒产出 1 个题库分片，来源名 = 上传文件名（不做「按文件内标题命名」，避免标题相同导致题库分裂，见 P2-6）；全文找不到任何 `## ` 标题时整体失败，报错需包含行号与期望写法：「第 12 行：未找到题目标题，需要 `## 1. [单选题]` 形式」。

### v1.3.6 点击填答案的交互细节

| 场景 | 行为 |
|---|---|
| 单选题 | 点字母 → 答案 = 该字母（覆盖原值）；再点同一字母 → 答案清空 |
| 多选题 | 点字母 → 追加进答案并按 A→H 升序归并（`AB`+`D` → `ABD`）；再点已选字母 → 移除；移除后剩余为空则答案为空 |
| 判断题 | 只显示 `√` `×` 两个按钮；选一个另一个自动取消；再点已选项 → 答案清空；切换题型到判断题时清空选项区与答案 |
| 未填内容的选项 | 按钮置灰不可点，`title` 提示「请先填写选项 D 的内容」；删除中间选项时后续字母前移（删 B 后 C→B），答案中被删字母同步移除并提示「答案已随选项调整」 |
| 双向同步 | 手输答案框时，按键去重、转大写、忽略分隔符（`A,B` → `AB`）；合法时点选区同步高亮 |
| 非法输入 | 出现非 A–H 字符、字母超出已填选项、或多选题只输 1 个字母之外的空值 → 输入框下方红字「答案只能是已填写选项的字母组合，判断题请用 √ / ×」，保存按钮禁用 |
| 空值判定 | 题干 <3 字、选择题选项 <1 个、答案为空 → 保存禁用并逐项提示；但**选项少于 4 个不阻塞保存**，落 `too_few_options` 异常交给异常校对页处理（与导入行为一致） |

### v1.3.7 兼容与迁移

- **历史数据零改动**：`file_type` 为 `docx/txt/pdf` 的历史 `import_files` 记录、其题目、异常、`anomalies` 处理状态全部原样保留；来源展示仍是原文件名。不做数据迁移、不重算 FTS；v1.2 遗留的 `pending_confirm` 批次仍可 commit / 删除，不受本次收敛影响。
